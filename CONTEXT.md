# Subkit Public Site

The public product surface where developers learn about Subkit, evaluate its commercial offering, follow product availability, and begin integrating Subkit.

## Language

**Public Site**:
The externally accessible Subkit experience for product discovery, documentation, pricing, roadmap, status, and contact.
_Avoid_: Landing page, marketing mockup

**Pricing Catalog**:
The published plans, prices, limits, and commercial terms available to prospective Subkit customers.
_Avoid_: Pricing copy, calculator constants

**Pricing Quote**:
An estimate derived from a Pricing Catalog and a prospective customer's usage assumptions.
_Avoid_: Final invoice, guaranteed charge

**SDK Guide**:
Versioned integration guidance and examples for a supported Subkit client SDK.
_Avoid_: API Reference, code mockup

**API Reference**:
The authoritative description of Subkit's public REST operations and schemas.
_Avoid_: SDK Guide, handwritten endpoint list

**Roadmap**:
The published sequence and current state of planned Subkit product capabilities.
_Avoid_: Release history, guaranteed delivery schedule

**System Status**:
The current reported availability of Subkit's production capabilities.
_Avoid_: Uptime promise, static status badge

**Operational**:
A System Status condition indicating that a capability is functioning normally.

**Degraded**:
A System Status condition indicating that a capability is available with reduced performance or partial impairment.

**Outage**:
A System Status condition indicating that a capability is unavailable.

**Unknown**:
A System Status condition indicating that current availability cannot be determined from the authoritative source.
_Avoid_: Operational fallback

**Contact Inquiry**:
A prospective or existing customer's message requesting information or assistance from Subkit.
_Avoid_: Support ticket, Telegram message

**Internal Services**:
The authoritative Subkit system for public product data and operational capabilities consumed by the Public Site and other Subkit clients.
_Avoid_: Website backend, mock API
