# Feature visibility notes

This file records intentionally hidden or deferred public-site elements so they are not mistaken for deleted work.

## Current rules

- Product capabilities that do not exist yet must be described as roadmap items.
- Subkit is aligned with open-source and Next Generation Internet principles; do not describe it as funded, endorsed, or supported by NGI unless a grant is formally awarded and the wording is approved.
- Private provider adapters and credentials belong in `subkit-internal-services`, never in this repository.
- Pricing and roadmap may use clearly identified temporary local snapshots until authoritative internal APIs are connected.
- System Status must show `Unknown` when an authoritative health source cannot be reached.

Update this note whenever an intentionally hidden feature is restored or its ownership changes.
