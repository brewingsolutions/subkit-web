# Contributing

Subkit Web is in an early, unstable foundation phase. Discuss substantial product or architecture changes before investing in a large implementation.

1. Read `CONTEXT.md`, `AGENTS.md`, and relevant decisions under `docs/adr/`.
2. Create a focused branch and keep private credentials out of commits.
3. Add or update tests for behavioral changes.
4. Run `npm test`, `npm run lint`, `npx tsc --noEmit`, and `npm run build`.
5. Open a pull request describing the user-facing change, verification, and any operational requirements.

By contributing, you agree that your contribution is licensed under Apache-2.0.
