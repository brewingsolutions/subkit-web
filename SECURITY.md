# Security policy

Subkit Web is an early-stage project. Security fixes are accepted for the current development branch; no stable release line is supported yet.

Please do not disclose vulnerabilities in a public issue. Send a concise report to `security@subkit.eu` including the affected version or commit, reproduction steps, impact, and any suggested mitigation. Do not include real customer data or secrets.

We will acknowledge reports as capacity allows and coordinate disclosure after a fix is available.
